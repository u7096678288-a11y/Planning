# LRD Planning Monitor

A responsive, searchable dashboard for monitoring Irish Large-scale Residential Development (LRD) planning applications.

## Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`. The interface links back to the Irish Planning Applications dataset on GeoHive as its source of record. The records included in this prototype are representative demo data and should be replaced by a live data integration before production use.
